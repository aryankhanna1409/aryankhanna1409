Final-year robotics engineer, **moving up the stack** from machines to the AI and software that run them.

I'm finishing a **B.Tech in Robotics & Automation** at Symbiosis Institute of Technology, Pune (2023–2027), with a diploma in business administration from SIBM Pune on the side. Since September 2024 I've been a research assistant across machine learning, autonomous robotics and computer vision: an IoT-enabled autonomous mobile robot, a multimodal RGB-thermal search-and-rescue system, and a published ML model for credit-card reward personalisation.

The through-line is systems. A robot is a sensing-and-decision pipeline, and a model is only useful inside a system that feeds and checks it.

- **Interested in:** computer vision, embedded systems, applied AI
